# Viktor Workflow Portable — очищений загальний пакет

Компактні правила аналізу й архітектури, порожні шаблони бізнес-аналізу, досвіду та відновлення і 12 оригінальних умовних діаграм: 25 експортів без потреби мережі та 8 необов’язкових прикладів для сторонніх засобів. Це **не повна приватна конфігурація автора**. Особистий профіль, чужі акаунти та права, приватні посилання, журнали проєктів, Git-історія, облікові дані й сторонні засоби побудови або знімки їхніх джерел не включені.

## Власне встановлення

1. Отримайте очищений ZIP, маніфест і SHA256 через погоджений канал. Звірте довірену SHA256 до розпакування; перевірте шляхи, типи файлів і CRC у новому каталозі. Не виконуйте код з архіву до перевірки джерела.
2. Прочитайте LICENSE та PROVENANCE.json. Вкладені оригінальні матеріали поширюються за MIT; сторонні засоби не вкладені й мають власні умови. `references/diagrams/sources.json` містить першоджерела, зафіксовані версії та межі перевірки, а не дозвіл автоматичного виконання.
3. Для хмарного використання завантажте ZIP через підтримуваний Plugin Creator у **своєму** акаунті й створіть власний приватний плагін. Для окремого Codex установіть `skills/workflow-portable` у підтримуваний каталог навичок після порівняння та резервування наявної однойменної навички. Особисті налаштування задайте самостійно; доступ автора не переноситься.
4. Для локальних перевірок потрібен Python 3.10+ зі стандартною бібліотекою. З кореня розпакованого пакета:

   ```text
   python3 -I -S verify_package.py .
   python3 -I -S skills/workflow-portable/scripts/diagram_library.py check
   python3 -I -S skills/workflow-portable/scripts/diagram_library.py lookup bpmn --limit 2
   ```

5. Новий сеанс має фактично бачити `workflow-portable`. Попросіть проаналізувати умовну задачу бізнес-аналізу, прочитавши лише шаблон аналізу й одну релевантну діаграму. Чужі доступи не підключайте. Для відкату окремого встановлення приберіть лише цю нову навичку й відновіть власну попередню копію; для хмари застосуйте власний штатний механізм.

Оригінальні експорти без мережі перевірені; сторонні засоби PlantUML/Mermaid/D2/Structurizr/Diagrams тут не запускалися. Для них потрібні окремі перевірені залежності, наприклад Java/Graphviz або Node відповідно до засобу й версії. Пакет не запускає інсталяторів. Експорти BPMN не є рушієм виконання процесів чи повною сертифікацією XSD. Приватні моделі зовнішнім сервісам без дозволу не надсилайте.

Сканер перевіряє конкретні маркери приватних даних, облік файлів, контрольні суми й локальні посилання. Це не доказ відсутності всіх можливих секретів чи шкідливого коду. Ізольовані тести не є фізичною перевіркою іншого комп’ютера або доступності в іншому хмарному акаунті. Розкладу й автоматичного оновлювача не створено.
